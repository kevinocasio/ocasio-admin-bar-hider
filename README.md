# Ocasio Admin Bar Hider

> Lightweight WordPress plugin to hide the admin bar for non-administrators on the front end and clean up backend toolbar clutter.

## Overview

For membership sites, stores, or client blogs, **Ocasio Admin Bar Hider** hides the front-end toolbar for non-administrators, giving subscribers and clients a distraction-free experience.

## Features

* **Hide Front-End Bar:** Completely hides the toolbar for non-admin roles on public pages.
* **Minimalist Backend Toolbar:** Strips out plugin clutter in the dashboard for non-admins.
* **Profile Option Guard:** Hides the toolbar toggle setting on user profile screens.
* **Zero Front-End Assets:** Pure PHP execution with 0 bytes of extra CSS or JS loaded on public pages.
* **Instant Dashboard Toggle:** Manage and toggle the switch directly from the **Ocasio Plugins** dashboard.

## Installation

1. Click the green **`< > Code`** button at the top of this repository and select **Download ZIP** (or download from [Releases](../../releases)).
2. In your WordPress admin dashboard, navigate to **Plugins -> Add New Plugin -> Upload Plugin**.
3. Choose the downloaded `ocasio-admin-bar-hider.zip` file and click **Install Now**.
4. Click **Activate Plugin**.
5. Manage settings directly under the **Ocasio Plugins -> Dashboard** menu.
